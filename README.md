# AERS Flash Bracket Full downloads

## Full 1.4.91

Download the [Windows installer ZIP](https://github.com/Coreyflash/AERSFLASHBRACKET-RELEASES/releases/download/v1.4.91/AERS-Flash-Bracket-V1.4.91-Windows-Installer.zip), extract it, and run **AERS-Flash-Bracket-Setup.exe**. Use the desktop shortcut after setup.

See the [latest release](https://github.com/Coreyflash/AERSFLASHBRACKET-RELEASES/releases/latest) for the installer, signed automatic-update package, checksums, and release notes.

This version fixes registration controls overlapping Done and oversized action buttons on narrow screens. Full's existing multi-bracketer features remain included.

Existing installations can prepare signed updates automatically. Save and close the event, then reopen to install a ready update. Saved events, settings, backups and approved pending exports are preserved. Saving and closing remain local; sending results requires an explicit submission.

Public installers and signed automatic-update files only. No application source or operator event data is published here. The Windows setup executable is not Authenticode-signed; automatic updates are authenticated separately using the embedded AERS publisher key.
